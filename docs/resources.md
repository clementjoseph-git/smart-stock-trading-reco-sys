# Resources

## 📊 Market Data APIs
- [Yahoo Finance API](https://pypi.org/project/yfinance/) — stock quotes, fundamentals
- [Alpha Vantage API](https://www.alphavantage.co/documentation/) — technical indicators, forex, crypto
- [NSE India](https://www.nseindia.com/) — official feeds for Indian markets
- [BSE India](https://www.bseindia.com/) — official feeds for Indian markets

## 🤖 Hugging Face Models
- [FinBERT](https://huggingface.co/yiyanghkust/finbert-tone) — financial sentiment analysis
- [Informer](https://huggingface.co/thuml/informer) — transformer-based time-series forecasting
- [Prophet](https://facebook.github.io/prophet/) — forecasting library (alternative to LSTM)
- [Bloom](https://huggingface.co/bigscience/bloom) — multilingual NLP for global financial news
